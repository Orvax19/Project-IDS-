# Project-IDS-
Un mini programme que j'ai mit au point pour pouvoir scanner le traffic réseau d'un PC afin d'y repéré des anomalies et de les signaler à l'utilisateur grace notamment au GUI qui est l'interface graphique de mon programme 

pour que celui si soit fonctionnel sur Windows il faut tout d'abord changé l'extension de ses deux fichiers qui sont en (.txt) pour (.py) puis installer de nombreuses dépendances notamment 

- Ncap
- python 
- les bibliothèques python :
- Time
- re
- argparse
- traceback
- collections
- threading
- sys
- tkinter
- scapy
- matplotlib
- pttsx3
- keyboard 

nb : ce programme n'as été développée que pour Windows et nécessite l'installation de python car c'est grâce à celui si qu'il a été mit au point.
